# Pixelmon Battle Effectiveness (Minecraft 1.21.1 NeoForge)

Клиентский мод/аддон для **Minecraft 1.21.1 (NeoForge)** и **Pixelmon Reforged (9.4.x)**, который отображает эффективность типов атак и множители урона в **каждой битве** у каждой атаки (точно так же, как в рейдах с боссами, но теперь везде).

---

## 🌟 Почему в оригинальном Pixelmon это работало только в рейдах?

В оригинальном коде Pixelmon (`ChooseAttack$MoveButton`) разработчики уже заложили систему подсказок эффективности атак (иконка + текст), но добавили два жестких ограничения:
1. `ClientStorageManager.pokedex().hasCaught(enemy)` — подсказки показывались **только** для тех покемонов, которые уже пойманы и занесены в Покедекс игрока (как в играх Pokémon Sun/Moon и Scarlet/Violet).
2. `displayedEnemyPokemon.length <= 1` — в битвах с несколькими противниками (Double Battles) подсказки отключались.

В рейдах босс всегда один и регистрируется особым образом, поэтому там система срабатывала. Данный мод снимает эти ограничения и делает систему умной и универсальной для **любых** сражений.

## ✨ Возможности мода

- 🎯 **Работает во всех типах битв:**
  - Дикие покемоны (Wild battles)
  - Битвы с NPC-тренерами (Trainers)
  - Лидеры стадионов (Gym Leaders)
  - PvP битвы между игроками
  - Рейды (Raids & Tera Raids)
- ⚔️ **У каждой атаки:**
  - **Сверхэффективно (4x)** (`Hyper Eff. (4x)`) — с двойной стрелкой вверх
  - **Суперэффективно (2x)** (`Super Eff. (2x)`) — со звездой / стрелкой вверх
  - **Эффективно (1x)** (`Effective (1x)`) — стандартный нейтральный урон
  - **Не очень эфф. (0.5x)** (`Not Very Eff. (0.5x)`) — со стрелкой вниз
  - **Едва эфф. (0.25x)** (`Barely Eff. (0.25x)`) — с двойной стрелкой вниз
  - **Не действует (0x)** (`Immune (0x)`) — иконка невосприимчивости
- 👥 **Поддержка Double Battles (2v2):**
  - Автоматически определяет выбранную/наведенную цель, либо первого живого противника (без сбоев и вылетов при нокауте первого противника).
- 💎 **Поддержка Терасталлизации и Инверсных битв:**
  - Учитывает смену типа при терасталлизации босса/противника.
  - Учитывает правила Inverse Battle.
- ❄️ **Особые атаки:**
  - Корректно рассчитывает `Freeze-Dry` (Фриз-Драй суперэффективен 2x против Водного типа).
  - Корректно рассчитывает `Thousand Arrows` (Тысяча стрел попадает по Летающему типу).
- 🇷🇺 **Полная локализация:**
  - Качественный русский перевод (`ru_ru`) и английский (`en_us`).
- ⚙️ **Гибкая конфигурация:**
  - Создается файл `config/pixelmoneffectiveness-client.toml`, где можно настроить показ множителей, нейтральных 1x атак или статусных приемов.

## 🚀 Установка

Готовый скомпилированный файл **уже скопирован** в вашу папку модов:
`%appdata%\.minecraft\mods\PixelmonEffectiveness-1.21.1-1.0.0.jar`

Также файл собран в проекте:
`build/libs/PixelmonEffectiveness-1.21.1-1.0.0.jar`

Достаточно запустить игру через лаунчер с установленным профилем NeoForge 1.21.1 и зайти в любую битву!
